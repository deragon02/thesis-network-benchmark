# Thesis Network Benchmark

ابزار آزمایشگاهی برای اندازه‌گیری کنترل‌شدهٔ ظرفیت شبکه بین دو سرور تحت مالکیت یا مجوز پژوهشگر.

## دامنه و ملاحظات اخلاقی

این پروژه برای تولید ترافیک مصنوعی دائمی، تغییر نسبت مصرف دیتاسنتر یا ارسال به سرورهای عمومی طراحی نشده است. تست فقط باید بین دو endpointای اجرا شود که شما مالک آن‌ها هستید یا اجازهٔ کتبی استفاده از آن‌ها را دارید.

## ویژگی‌ها

- تست کوتاه و یک‌باره با `iperf3`
- سقف پیش‌فرض سرعت: `500Mbit/s`
- مدت پیش‌فرض: 30 ثانیه
- بررسی وجود `iperf3` و معتبر بودن مدت و نرخ
- ثبت خروجی در فایل گزارش
- بدون تولید فایل یک‌گیگابایتی و بدون ارسال به سرویس‌های عمومی

## نصب

روی هر دو سرور Debian/Ubuntu:

```bash
sudo apt-get update
sudo apt-get install -y iperf3
```

## اجرای سمت آلمان

فقط روی سرور مقصد و در پنجرهٔ زمانی آزمایش اجرا کنید:

```bash
./server.sh
```

پورت پیش‌فرض `5201` است. در صورت نیاز فقط IP سرور ایران را در فایروال مجاز کنید.

## اجرای سمت ایران

```bash
./client.sh IP_SERVER_ALMAN 30 500M
```

پارامترها:

1. آدرس سرور iperf3 در آلمان
2. مدت آزمایش برحسب ثانیه؛ حداکثر 120
3. نرخ UDP؛ پیش‌فرض `500M`

برای جهت معکوس:

```bash
./client.sh IP_SERVER_ALMAN 30 500M reverse
```

## پاک‌سازی

پس از پایان آزمایش، سرویس iperf3 و پورت آزمایش را ببندید:

```bash
sudo systemctl stop iperf3 2>/dev/null || true
sudo systemctl disable iperf3 2>/dev/null || true
```

## تفسیر نتایج

خروجی شامل نرخ ارسال، jitter و packet loss است. مقدار واقعی ممکن است به‌دلیل تونل، سربار رمزنگاری، مسیر شبکه و ظرفیت CPU کمتر از سقف تعیین‌شده باشد. برای گزارش پایان‌نامه، زمان، نرخ، جهت، RTT، packet loss و مشخصات دو endpoint را ثبت کنید.
